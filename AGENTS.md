# Repository Guidance

Maintain the Joplin plugin scaffolding skill in `skills/joplin-plugin-scaffold/`.
Its `assets/AGENTS.md` is an output template for generated projects.

Write skill instructions and project documentation in English.
Read `docs/design.md` before changing the agreed scaffolding behavior.

## Agent skills

### Issue tracker

Use GitHub Issues for the working repository, resolving the target from the user's request or Git remotes.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context glossary and ADR layout.
See `docs/agents/domain.md`.
