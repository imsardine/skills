# Agent Skills

Shared language for the skills in this collection and their outputs.

## Language

### Joplin plugin scaffolding

**Scaffolding**:
A new, buildable plugin project retaining the official generator's starter code, with metadata and guidance for future contributors.

**Plugin directory**:
The root directory of a new plugin project.

**Npm package name**:
The `name` in `package.json`, identifying the npm package. Joplin's automatic repository inclusion requires it to start with `joplin-plugin-`.

**Plugin ID**:
The `id` in the plugin manifest, identifying the plugin to Joplin. The default convention here is `joplin.plugin.xxx`.

**Plugin display name**:
The `name` in the plugin manifest, presented to users.

### Scenario dialogue practice

**Scenario**:
The situation supplied by the learner in which a practice dialogue takes place.

**Dialogue plan**:
The intended exchange that determines how a scenario progresses, independently of the correctness of the learner's responses.

**Native language**:
The learner's language used for dialogue cues and learning explanations.
_Avoid_: Source language

**Target language**:
The language the learner is practicing expressing those meanings in.

**Dialogue role**:
One of the two characters whose lines the learner practices in a scenario.

**Native-language cue**:
A role-labeled line in the learner's native language conveying what to express next in the target language.

**Learner response**:
The learner's actual attempt to express a cue, including any native-language wording used within the attempt.

**Learning material**:
A post-dialogue resource explaining how to express the dialogue's intended meanings in context and addressing the learner's actual responses.

### English learning from notes

**Learning item**:
A reusable English word, expression, or sentence pattern identified from marked original text, with repeated occurrences consolidated into one practice item.

**Follow-up question**:
A learner's supplementary thought or question about a learning item, considered together with its original context and practice explanations.

**Practice section**:
The note's single collection of learning-item explanations and bilingual dialogue examples, ordered by the items' first appearance in the original text.
