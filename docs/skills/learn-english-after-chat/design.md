# Learn English after chat: Design

## Purpose and scope

Help users learn to express their own intentions naturally in American English by reviewing an existing conversation, with explanations in Traditional Chinese and a standalone Markdown learning document.

The [skill](../../../skills/learn-english-after-chat/SKILL.md) owns the selection, annotation, and delivery instructions. The [usage guide](usage.md) explains how to request the output.

## Packaging

The skill is self-contained in one instruction file. It needs no scripts, references, or assets. UI metadata provides the display name; user documentation lives alongside this record rather than in the executable skill folder.

The instructions are written in English. Traditional Chinese is deliberately retained in the annotation format because it is part of the requested learning output.
