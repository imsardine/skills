## Repository layout

- `skills/<skill-name>/`: agent instructions and the resources needed to execute that skill.
- `docs/skills/<skill-name>/`: usage guides and design records for an individual skill.
- `docs/agents/`: shared repository maintenance workflows.
- `AGENTS.md`: contributor instructions for this repository.
- `GLOSSARY.md`: shared domain vocabulary.
