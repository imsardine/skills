# Agent Skills

A collection of reusable skills for a range of tasks.

## Available skills

| Skill | Purpose | Documentation |
| --- | --- | --- |
| [joplin-plugin-scaffold](skills/joplin-plugin-scaffold/SKILL.md) | Create a Joplin plugin project with the official generator and guidance for future development. | [Usage](docs/skills/joplin-plugin-scaffold/usage.md) |
| [Learn English after chat](skills/learn-english-after-chat/SKILL.md) | Learn natural American English from a conversation, with explanations in Traditional Chinese. | [Usage](docs/skills/learn-english-after-chat/usage.md) |
| [Scenario dialogue practice](skills/scenario-dialogue-practice/SKILL.md) | Practice both dialogue roles from native-language cues, then review feedback, IPA vocabulary notes, and links to a chosen online reader. | [Usage](docs/skills/scenario-dialogue-practice/usage.md) |

## Repository layout

- `skills/<skill-name>/`: agent instructions and the resources needed to execute that skill.
- `docs/skills/<skill-name>/`: usage guides and design records for an individual skill.
- `docs/agents/`: shared repository maintenance workflows.
- `AGENTS.md`: contributor instructions for this repository.
- `GLOSSARY.md`: shared domain vocabulary.
